# 查看数据库结构的工具

## 支持功能
1. 查看数据库结构
2. 显示在窗口最前端
3. 支持各种复制
4. 支持多窗口：主窗口只配置数据库连接，子窗口负责查询和显示表信息
5. 支持多数据源连接，每个子窗口按打开时选择/填写的 JDBC 连接直连数据库
6. 支持本地保存历史数据连接，并可为连接起名后在主窗口中快速切换
7. 目前元数据查询 SQL 面向 PostgreSQL
8. 目前主要支持 Windows 桌面环境

## 使用方式
1. 在主窗口填写或选择数据库连接，可点击“保存连接”保存历史连接。
2. 点击“打开表信息窗口”创建子窗口。
3. 在子窗口输入表名查询字段信息，或使用 Ctrl+D 粘贴剪贴板表名并查询。

## 连接历史
连接历史保存到当前用户目录下的 `.databasemeta/connections.json`。保存内容包含连接名称、JDBC URL、用户名、密码、驱动类和 schema。
