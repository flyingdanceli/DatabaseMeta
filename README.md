# 查看数据库结构的工具

## 支持功能
1. 查看数据库结构
2. 显示在窗口最前端
3. 支持各种复制
4. 支持多窗口，可在应用内点击“新窗口”打开独立查询窗口
5. 支持多数据源连接，每次查询按当前窗口填写/选择的 JDBC 连接直连数据库
6. 支持本地保存历史数据连接，并可为连接起名后在窗口中快速切换
7. 目前元数据查询 SQL 面向 PostgreSQL
8. 目前主要支持 Windows 桌面环境

## 连接历史
连接历史保存到当前用户目录下的 `.databasemeta/connections.json`。保存内容包含连接名称、JDBC URL、用户名、密码、驱动类和 schema。
